# superstore-business-analysis
End-to-end SQL business analysis on 9,800+ Superstore sales records — RFM customer segmentation, regional performance  analysis, YoY growth trends, and data-driven recommendations using SQLite.

## Why I built this

I'm currently looking for a data analyst internship and I wanted to build 
something that actually shows how I think — not just that I can run queries.

I started by opening the dataset in Excel and just looking at it. That's 
where I found the real questions — which regions are losing money, where 
are customers dropping off, what's not selling. I didn't start with SQL. 
I started with "what's going wrong here and can we fix it?"

SQL came after. I'm comfortable with queries but I'll be honest — some of 
the advanced stuff like RFM segmentation I figured out as I went. That's 
kind of the point though. I wanted to push past the basics.

The question I kept asking myself throughout was: if I had to present this 
to a manager tomorrow, what would actually matter to them? Not the charts. 
The answer to — where are we losing money and what do we do about it.
